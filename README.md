# javascript-calculator
Summative Lab for a JavaScript Calculator
It's a simple calculator that handles basic arithmetic operations and keeps a history of all calculations made and displays the history.

#Fetures
The arithmetic features it has are:
- Addition
- Subtraction
- Multiplication
- Division
- Store calculation history
- Display previous calculations

#Workings
The calculator accepts two numbers and an operator. 
Each calculation is stored in an array as an object containing the following;
- first operand
- second operand
- operator
- result 

#Running the Program
Make sure Node.js is installed.
Run the calculator using:
node calculator.js

Example
calculate(17, 2, "/");
calculate(98, 10, "+");
calculate(10, 3, "*");
calculate(10, 6, "-");

Example results:
8.5
108
30
4

The calculations are also stored in the calculation history.
